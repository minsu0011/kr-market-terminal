# 외부 분석 모델의 역할

이 서비스의 주된 산출물은 여러 데이터를 읽고 분석·경보·가상 거래로 연결하는 end-to-end 흐름이다. LLM은 구조화된 입력의 해석·설명을 담당하며 시세 공급자, feature 계산기, 수익성 검증기와 다르다.

FeatureRegistry가 허용하는 feature와 상태를 입력으로 넘기고, AiJobManager가 작업 진행을 관리한다. AlertEvaluator가 적용할 경보와 분석 요청의 내용을 구분한다.

따라서 외부 모델명을 자체 예측 모델의 개선 계보로 나열하지 않는다. 연동 API와 service boundary, 입력 가용성, 오류 처리와 상태 전송이 직접 구현한 부분이다.
