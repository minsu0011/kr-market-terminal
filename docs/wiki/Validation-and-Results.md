# 확인한 결과와 범위

2026-10-13 로컬 pytest 54개가 통과했습니다. 외부 HTTP를 차단한 테스트와 fixture·임시 DB를 사용했고, 브라우저를 띄우는 대신 TestClient로 HTML·Plotly·분봉 응답을 확인했습니다.

데모에서는 로컬 뉴스만 사용하도록 공급자를 제한했습니다. public/KIS의 실제 네트워크 조회와 외부 LLM 호출은 검증하지 않았습니다. GitHub Actions의 실행 결과도 로컬 결과와 구분합니다.

소프트웨어 결과는 시세·뉴스·표준 피처·로컬 상태·화면 전달을 연결한 것입니다. 가격 방향 정확도, 수익률 또는 거래소급 피드 운영을 인증하지 않습니다. 전체 원시 봉을 보존하거나 완전한 PIT 결합을 제공하는 구조도 아닙니다.
