# 소프트웨어 결과와 금융 성과

뉴스 처리와 AI 분석 경계에 대한 test가 있으며, API·WebSocket·UI·SQLite와 가상매매를 연결했다. 이 사실은 투자 수익이나 방향 정확도가 검증됐다는 의미가 아니다.

외부 provider의 지연·권한·coverage, LLM 응답 오류와 비용, 로컬 상태의 동시 접근을 주의해야 한다. unavailable feature를 0인 정상 관측으로 읽으면 분석 의미가 바뀐다.

[테스트 기록](../testing-notes.md)은 실행한 범위와 외부 API를 호출하지 않은 범위를 구분한다. 로컬 인증정보는 원문 값을 기록하지 않고 Windows secret store로 관리한다.
