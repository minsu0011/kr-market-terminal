# 남은 문제

이 도구는 브로커 API·공개 조회를 모아 보는 로컬 터미널입니다. 거래소 피드, FIX·multicast, 고가용성 또는 저지연 운영을 구현했다고 주장하지 않습니다.

## 시간과 원자료

- 최신 재무·거시 값은 현재 스냅샷에 병합합니다. 과거 분봉 시점의 발표 가용성·수정 이력을 재구성하는 PIT join은 없습니다.
- 날짜만 제공된 OpenDART 공시를 자정으로 바꾸는 경로가 있습니다. 이 시각을 실제 공개 시각으로 읽으면 뉴스 반응 시간이 잘못됩니다.
- 뉴스 horizon 이상인 첫 봉을 고르므로 장외 사건에서 1·3·5·15분 반응이 같은 봉을 가리킬 수 있습니다.
- 원시 tick·분봉 전체를 보존하지 않아 과거 화면 결과를 독립적으로 재계산하기 어렵습니다.
- 현재 수급은 당일 누적값일 수 있고 뉴스 이후 증분을 뜻하지 않습니다.
- 과거 가상거래 입력에 최신 피처가 섞일 수 있어 성과 백테스트로 사용하면 안 됩니다.

## 규칙과 상태

- 계약·공급·해지 같은 단어의 단순 개수로 방향을 정하면 계약 해지를 긍정으로 분류할 수 있습니다.
- 후보 확인 점수와 데이터 품질 점수는 확률·승률·정확도 인증이 아닙니다.
- KIS 마지막 체결을 반복 처리하며 거래량을 더할 수 있는 위험이 남아 있습니다. sequence 기반 중복 제거와 누락 복구가 필요합니다.
- stale cache와 feed 중단 상태를 모든 원천에서 일관되게 표시하지는 못합니다.
- 회원사 창구와 기관 투자자, 업종 ETF proxy와 개별 회사 사실을 구분해야 합니다.

## 범위

EPS/PER/PBR 활성 계산, 바이오 임상 성공 예측, 훈련된 상승·하락 모델, 전체 통계 백테스트 엔진은 포함하지 않습니다. 외부 LLM은 설명 기능이며 현재 모델 접근 여부는 별도 검증해야 합니다.
