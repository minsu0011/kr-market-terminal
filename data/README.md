# 로컬 데이터

저장소에는 빈 수동 입력 템플릿 두 개만 포함합니다.

- external_features.json: global 또는 symbols 아래에 피처 값을 넣습니다.
- news_manual.json: 직접 확인한 뉴스의 items 배열입니다.

앱을 실행하면 이 디렉터리에 SQLite와 설정 파일이 생성될 수 있습니다. 이 파일들은 Git에서 제외합니다. template 내용을 수정해 실제 관측값을 넣었다면, 그 값을 그대로 커밋하지 않도록 주의하세요.

비밀키는 화면의 API 설정에서 입력합니다. Windows DPAPI 암호화 파일과 연결 상태 파일을 사용하며 키 원문을 .env나 Git에 넣지 않습니다. 다른 Windows 사용자나 PC로 키 파일을 복사해 재사용하는 방식은 지원하지 않습니다.

SQLite에는 뉴스·지표 스냅샷·분석·가상거래 상태를 저장합니다. 원시 체결이나 OHLCV 전체를 보존한 시세 데이터베이스는 아닙니다. 데이터 공급자의 접근 권한과 이용 조건은 코드의 이용 범위와 별개입니다.
